# Plant_Disease_Detection_Model

This is a deep learning-based web application that detects plant diseases from leaf images using Convolutional Neural Networks (CNN) and MobileNetV2.

The application allows users to upload an image of a plant leaf and receive a predicted disease name, confidence score, and basic recommendations through a simple and user-friendly interface.

---------------------------------------------------------



# Technologies Used:
Python 3.11 – Programming language

TensorFlow & Keras – Deep learning framework

MobileNetV2 – Pre-trained CNN architecture

NumPy – Numerical operations

Pillow (PIL) – Image processing

Streamlit – Web application development

GitHub – Source code management and hosting

---------------------------------------------------------


# Dataset:
This project uses the PlantVillage dataset, containing approximately 55,448 images across 39 classes, including healthy and diseased plant categories.

The dataset was used for training and evaluating the image classification model.
